# Roadster 2 垂直起降概念网站

## 公开演示

[打开 Roadster 2 网页](https://liamjake102291-create.github.io/roadster-2-flight/)。可将此 HTTPS 地址作为 PowerPoint 中图片、文字或按钮的超链接。

## 打开网站

Windows 解压后双击 **Start Roadster.cmd**。也可以在目录里运行 `node scripts/preview.mjs`，然后打开 `http://127.0.0.1:4173/`。预览使用现成的 `dist` 目录，需要 Node.js 和支持 WebGL 的浏览器。启动和浏览都可离线进行。

## 页面操作

- **首次打开** 约 50.5 秒，依次演出开场、飞跃车列、爬坡发射、空中拆解、复装和降落。前导为 8.4 秒的实时三维蒙太奇，随后进入按 2026-11-23 录屏时间编排的坡道发射。开启系统减少动态效果时，可手动播放。
- **坡道与喷流** 录屏时间轴约 10.6 秒停稳、12.45 秒启动尾喷、13.10 秒离轨、18.70 秒接地、23.10 秒停车。采用分离的尾喷、翻滚脉冲、下喷承重、水平修正与接地余雾。参考时间由视频画面判断，精度受烟雾遮挡影响。
- **悬停交接** 悬停后自动展开 27 组总成，在完整爆炸图停留约 2.4 秒，再按原路径复装并开始降落。可暂停检视或跳到任一章节。拆解和复装占约 10 秒，期间悬停，原有降落段的动作时间保持独立。
- **手动控制** 用滚轮、触屏、进度条或八个章节按钮双向浏览。选“检视”到达完整爆炸图。
- **选件** 点击画面或零件列表。手机用下拉菜单浏览全部 27 组。
- **观察模式** 外观使用时间轴镜头。透视降低覆盖件不透明度。自由观察用鼠标或触控旋转、缩放。
- **零件工坊** 可单独查看整车爆炸图、储气罐、推进喷嘴、涵道风扇与电池包。

## 开发和部署

```sh
npm ci
npm run dev
npm run build
npm run test:e2e
```

`dist/` 可由普通静态 HTTP 服务托管，支持放在网站子目录。测试在有 Edge 的 Windows 上可直接使用 Edge，其他环境可以运行 `npx playwright install chromium`。

## 资产与动画

整车外观取自附带的 `Roadster2_Flight_Car.glb`。底盘、座舱、电驱、电池与部分飞行组件取自 `Roadster2_Parts_Assembly.glb`，按整车坐标重新定位。脚本 `scripts/prepare-model.mjs` 接收这两个 GLB 路径，按独立枢轴和材质合并网格，输出网页模型。车门接缝属于整车壳体。动力布局采用前后电驱概念。动画演示高度、喷流和悬停用于视觉叙事。

时间轴状态统一由页面滚动位置驱动。27 组总成共享同一组拆解和归位轨迹。三维场景使用 React、Three.js 与 React Three Fiber。

坡道发射动作参考 [Roadster Liftoff](https://aashishgtbit.github.io/roadster-liftoff/) 的 Ramp Hang 演示及其公开源码。网页使用交付包内原有的车辆资产。喷流采用按喷嘴位置和车身姿态计算的粒子近似，含简化阻力和地面扩散。

播放使用独立动画时钟，暂停或拖动时才同步页面滚动。连续播放会依次经过全部阶段。喷雾一次提交绘制，暂停时按需重绘。画面保留车辆环境反射和接地软阴影。

## 更新 GitHub Pages

运行 `npm ci` 安装依赖，再执行 `node scripts/build-pages.mjs`。把新生成的 `docs/` 和相应源码提交到 `main`。仓库 Pages 设置为 `main` 的 `/docs`。发布版并行下载开场几何与程序，首屏静态预览内嵌在首页。车身及座舱可先开始渲染，内部总成随后加载，进入结构扫描前自动等待需要的资产。两批资产从同一演示模型无损拆分，零件工坊中的整车视图仍可按需加载完整 GLB。

飞跃车列参考 [Roadster Liftoff 的 Lineup Jump](https://aashishgtbit.github.io/roadster-liftoff/)。车列与动作使用本站的几何与时间轴重建。
